# M5 관리자·실행 주기·비상착륙 — 2026-09-13

## 한 것

- `runner.py`: shell 없는 argv spawn, 환경 병합, 새 프로세스 세션, `RLIMIT_CORE=0`, PID/로그, 명령 수용표, server-owned 비동기 실행·종료, BT/preflight 감시를 구현했다. DONE에서도 살아 있는 BT PID를 유지한다.
- §5.5의 순서를 구현했다. LANDING을 먼저 확정하고 BT SIGINT 1회 → 0.5초 → 역할 드론 land와 LIMO CancelGoal → BT 종료 기한 → 필요 시 SIGKILL → preflight SIGINT → 신선하고 낮은 pose만 arm(false) → ABORTED 또는 reset IDLE로 간다. 외부·스페어 프로세스/기체를 제어 대상으로 늘리지 않았다.
- `ros_io.py`: 역할에만 land/arm/CancelGoal 클라이언트를 연결했다. 실제 ROS Future를 asyncio에 연결하고 응답/거부/미존재/1초 타임아웃을 구별한다. zero UUID/stamp는 해당 LIMO의 모든 Nav2 goal 취소다.
- `server.py`: 실제 관리자 명령을 Runner에 위임하고, aiohttp `on_shutdown`에서 열린 WS 핸들러 대기보다 먼저 안전 종료를 완료한다. ROS와 수신 집계는 안전 종료가 끝난 뒤 정리한다. 관리자 HTTP/WS는 loopback 및 동일 Origin으로 제한한다.
- `admin.html`, `admin.css`, `admin.js`, `admin-model.js`: READY/RUNNING/LANDING UI, 스크롤 중에도 보이는 제어 바, 0.6초 시작 hold, 즉시 비상착륙, 실패 상단·그룹 접기, 역할 6행, 카메라 fps/첫 JPEG 해상도, 신선한 고도 강조, 이벤트 30건·preflight 단계·외부 BT 배지·연결 배너를 추가했다.
- `ws.js`: 관리자 소켓 종료 즉시 또는 마지막 state 수신 1.5초에 잠근다. 타이머가 지연돼도 send 직전에 age를 재검사한다. visitor의 2초 유예는 유지한다. 1초 ACK 대기 후에는 수용표가 허용하는 estop만 재전송 가능하다.
- `state.py`, `mock.py`: 동일한 noop 명령도 각각 ACK 이벤트를 남긴다. 새 착륙 시작 경계 이후의 land 진행만 표시해 이전 회차 4/4가 재사용되지 않게 했다.
- 고아 BT/preflight는 PID·argv·Linux 시작 식별자를 대조한다. SIGINT 전송 전 atomic/fsync 기록을 저장하며, 백엔드가 착륙 중 죽었다가 재시작해도 같은 BT에 두 번째 SIGINT를 보내지 않는다.

## 스펙과 다르게 한 것

- 관리자 전용 부가 설정(착륙 z 기준)은 loopback `/api/admin`에서 받는다. hello는 v2.5의 16개 키를 그대로 유지한다.
- PID 신원과 SIGINT 전송 기록을 추가했다. 메모리의 `sigint_sent`만으로는 백엔드 재시작 경계를 지킬 수 없어 §5.5의 SIGINT 1회 계약을 디스크 기록으로 보장한다.
- 1.5초 만료는 polling 대신 수신마다 갱신하는 단발 타이머와 send age 검사로 구현했다.

## 열린 질문 / 사용자 결정 필요

- §5.5의 고아 `run/*.pid`와 §5.8의 독립 스택 수명 사이에서, 이전 대시보드가 남긴 **드론 서버·카메라 스택**을 외부 실행으로 유지할지, 역할 착륙 확인 후 종료할지 질문했다. BT/preflight 고아 복구는 구현·검증 완료했고, 스택 고아 정책 변경은 답변 전 적용하지 않았다. M6 보고서에도 추적한다.
- Webots·실기체는 실행하지 않았다. 실제 착륙·Nav2 정지·배터리·고도 수신률은 Stage A–D에서 확인한다.

## 다음 마일스톤에서 알아야 할 것

- M6는 같은 process spawn/종료 helper와 stack busy interlock을 사용한다. 안전한 IDLE에서만 `Runner.reconfigure()`로 착륙 설정을 다시 읽는다.
- source상의 안전 플래그·누락된 물리 URI/IP는 자동 수정하지 않았다. 실모드 기본 체크리스트는 운영자 설정이 완비되기 전까지 시작을 차단한다.
