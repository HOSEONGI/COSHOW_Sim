## 한 것

### M2 후속 수정

첫 커밋은 리뷰 §1.1의 필수 8건과 관련 회귀만 포함한다.

1. `ros_io.py`: 잘못된 템플릿·키·플레이스홀더를 항목별 오류로 반환하고 유효 채널은 계속 구독한다. `server.py`는 ROS 시작 실패에도 HTTP를 유지한다. 체크리스트의 인터페이스 오류는 blocking이다.
2. `config.py`, `ros_io.py`, `README.md`: 치명 설정 오류와 스페어 미기입 경고를 분리했다. **check-config는 치명 설정 오류 또는 확인 가능한 인터페이스/노드 FAIL이 있으면 rc=1, 그 외 rc=0; 명시적 null 타입 SKIP와 스페어 URI/IP 미기입 WARN은 제외한다.** 누락 타입 키는 null과 구분해 오류로 처리한다.
3. `checklist.py`: visualiser는 비차단 경고다. 역할 배정/URI/IP 오류와 스페어 미기입을 별도 항목으로 노출한다.
4. `mock.py`: 실제 어댑터의 채널 목록으로 수신을 제한한다. 스페어 드론 pose와 스페어 LIMO nav_ready는 공급하지 않는다. 실제 어댑터가 구독하는 전체 LIMO odom은 유지한다.
5. `state.py`: `run.elapsed_s`를 수신과 같은 monotonic 시계로 제공한다.
6. `ros_io.py`: 타입 설정의 미지원 키·누락 키를 검증한다.
7. `verify_m2_constraints.py`: 서비스/액션/AI Deck/marker/LIMO/spare 패턴을 포함해 검사하고 패턴과 내부 스키마 키 예외 목록을 출력한다. `spare_prefix`는 필수 설정이다.
8. `server.py`, `state.py`, `checklist.py`: 송신 예외 시 경고·닫기·소켓 제거, 집계 예외 후 다음 tick 계속, ready 단독 latch 표시, 외부 preflight 수신 목록의 긴 쪽 선택을 구현했다.

권장 사항도 적용했다: 잠금 안의 `set_run/set_stack`, LIMO 배터리 임계값 주석,
M2 보고서 RED/GREEN 입력 계수 구분, 프로브의 스페어 blocking 실제 관측값.
